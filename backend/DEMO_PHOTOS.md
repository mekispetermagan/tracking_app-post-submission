# Demo photo manifest

The demo database expects each filename below in both its original and
compressed directory. The image content must be fictional or cleared for
public demonstration.

## Session photographs

Place the original files in `original_photos/` and compressed copies with the
same filenames in `compressed_photos/`.

```text
demo_session_c01_20260713_01.jpg
demo_session_c01_20260713_02.jpg
demo_session_c01_20260713_03.jpg
```
